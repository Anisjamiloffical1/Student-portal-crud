# 🎓 Student CRUD Management System

A simple **Django-based CRUD (Create, Read, Update, Delete) web application** for managing student records. This project is designed for beginners to understand Django fundamentals and how database operations work in real-world applications.

---

## 🚀 Features

- Add new students
- View all students list
- Update student information
- Delete student records
- Responsive UI using Bootstrap 5
- CSRF protection enabled (Django security)
- Clean and simple interface

---

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML, Bootstrap 5
- **Database:** SQLite (default Django DB)
- **Template Engine:** Django Templates
